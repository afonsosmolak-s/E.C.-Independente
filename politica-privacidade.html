Política de Privacidade

Como o Esporte Clube Independente trata os dados pessoais dos visitantes deste site, em conformidade com a Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018).

2. Que dados coletamos

O site ecindependente.com é essencialmente informativo e não coleta dados sensíveis nem confidenciais dos visitantes.

Os únicos dados pessoais coletados diretamente por este site são fornecidos voluntariamente pelo próprio visitante no formulário de compra de uniforme oficial, sendo eles:

  • Nome completo
  • Número de telefone (WhatsApp)

Adicionalmente, o formulário solicita informações relacionadas ao pedido, que não são consideradas dados pessoais:

  • Modalidade esportiva de interesse
  • Tamanho da camiseta
  • Quantidade de uniformes
  • Forma de pagamento escolhida (PIX ou presencial)

Não coletamos: CPF, RG, endereço residencial, dados bancários, senhas, dados de cartão de crédito, dados de saúde, dados de menores sem autorização dos responsáveis, ou qualquer outra informação sensível prevista no art. 5º, II da LGPD.

3. Como usamos seus dados

Os dados coletados (nome e telefone) têm finalidade única e exclusiva de:

  • Gerar o comprovante de pedido em formato PDF, entregue ao próprio visitante
  • Permitir o contato do cliente com o clube via WhatsApp para finalizar a compra do uniforme
  • Confirmar recebimento de comprovante de pagamento
  • Combinar detalhes de entrega ou retirada do uniforme

Não utilizamos seus dados para publicidade, análise comportamental, criação de perfis ou envio de comunicação de marketing.

4. Base legal do tratamento

O tratamento de dados no formulário de compra é baseado nas seguintes hipóteses legais (art. 7º da LGPD):

  • Execução de contrato ou procedimentos preliminares (art. 7º, V): os dados são necessários para efetivar a compra do uniforme solicitada pelo próprio titular
  • Consentimento (art. 7º, I): manifesto pelo preenchimento voluntário do formulário

5. Compartilhamento de dados

O site não vende, aluga ou compartilha dados pessoais com terceiros para fins comerciais.

Os dados fornecidos no formulário permanecem no dispositivo do próprio visitante (para geração do PDF) e são enviados diretamente ao WhatsApp do clube pelo próprio visitante, através de link. Nesse envio, os dados passam por servidores do WhatsApp (Meta Platforms Inc.), sob os termos da própria plataforma.

O site utiliza recursos técnicos hospedados em redes de distribuição de conteúdo (CDN):

  • Google Fonts (fornecimento de fontes tipográficas)
  • jsDelivr (biblioteca de ícones Bootstrap Icons)
  • Cloudflare CDN (biblioteca jsPDF para geração do comprovante)

Essas plataformas podem registrar tecnicamente o endereço IP do visitante para prestação do serviço, sem qualquer identificação pessoal e sem transmissão de dados a nós.

6. Cookies

Este site não utiliza cookies próprios de rastreamento, análise ou publicidade. Consulte nossa Política de Cookies para detalhes.

7. Retenção dos dados

Os dados preenchidos no formulário de compra não são armazenados em nenhum banco de dados pelo site. O comprovante em PDF é gerado localmente no navegador do próprio visitante e enviado por ele ao clube via WhatsApp.

Uma vez recebidos pelo WhatsApp, os dados são utilizados exclusivamente para atender o pedido do cliente e ficam retidos pelo prazo mínimo necessário ao cumprimento do contrato e das obrigações fiscais aplicáveis.

8. Direitos do titular

A LGPD garante ao titular dos dados os seguintes direitos (art. 18):

  • Confirmação da existência de tratamento
  • Acesso aos dados
  • Correção de dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados
  • Eliminação dos dados tratados com base no consentimento
  • Informação sobre com quem os dados foram compartilhados
  • Informação sobre a possibilidade de não fornecer o consentimento e suas consequências
  • Revogação do consentimento a qualquer momento

10. Segurança

Adotamos medidas técnicas e organizacionais razoáveis para proteger os dados tratados por meio deste site, incluindo:

  • Conexão HTTPS (SSL) em todo o site
  • Processamento local no dispositivo do visitante (sem envio a nossos servidores)
  • Uso de canais oficiais e seguros para recebimento do pedido (WhatsApp)

11. Menores de idade

Algumas modalidades oferecidas pelo clube atendem crianças e adolescentes. Nesses casos, a matrícula, a compra de uniforme e o fornecimento de qualquer dado devem ser realizados pelos pais ou responsáveis legais, que declaram consentimento expresso ao efetuar tais ações.

12. Alterações desta política

Esta Política de Privacidade pode ser atualizada a qualquer momento para refletir mudanças legais ou operacionais. A data da última atualização estará sempre no topo do documento. Recomendamos consultar esta página periodicamente.

13. Legislação aplicável e foro

Esta política é regida pelas leis da República Federativa do Brasil, em especial pela Lei nº 13.709/2018 (LGPD). Fica eleito o foro da Comarca de Nova Europa/SP para dirimir eventuais controvérsias.
